SimReader: reading files

MessageWhat to do
Report tables missing: this EnergyPlus report is missing tables SimReader needsAdd the output tables to the IDF and rerun the simulation. See EnergyPlus and OpenStudio.
ES-D report missing: the .sim file has no ES-D reportThe eQUEST model has no utility rates. Add them and rerun the simulation.
Meter name warning: meters with the same first 4 characterseQUEST’s ES-D report keeps only 4 characters of a meter name. Rename one meter in the model so the first 4 characters differ.
Utility rate warning after readingThe baseline and proposed models use different rate names for a meter, so the designs are priced differently. Check the rates in both models.
File not foundThe file was moved or renamed. Update the file list on the Project page.
Read error or Report files can’t be readCheck that the simulation finished and the file is complete, then select Reload.
Same file as baseline and proposedThe savings would be zero. Add the proposed design’s own file. To report one design only, use a Parametric Analysis project and choose Parametric Analysis in SimReader.
More than one proposed fileThe proposed results are averaged. Keep one file unless you mean to average.
More than one base design fileParametric Analysis uses only the first base design file.
Files missing: add the base design fileA Parametric Analysis needs a base design file before it can read the ECMs.
Open failedThe .ine file isn’t a SimReader project or is damaged.

SimReader: signing in and uploading

MessageWhat to do
Sign in requiredGo to Settings > Sign in.
The email or password is incorrectCheck both. If you just signed up, confirm your email first.
No pinned projectsPin the project in InverseHub, then select Refresh in SimReader. See Pin the projects you’re working on.
No project selectedChoose the project on the Project page, then upload again.
Create a modeling phase?The phase doesn’t exist on InverseHub yet. Select Create and upload.
Replace results on InverseHub?The phase already has results. Select Replace to replace them.
Change the client?The client you chose differs from InverseHub’s. The change applies to every phase of the project.
Analysis type set from InverseHubThe project’s type differs from the one SimReader had selected, so SimReader switched. Check that your files are in the right lists.
The project’s analysis type in InverseHub isn’t the one selected in SimReaderThe project’s type was changed after you chose it. Select Reload from InverseHub, check the file lists, then upload again.
Upload failedSign out and sign in again under Settings, then try again. If it still fails, email support@inversenergy.com.
Upload stopped: more than one phase with this nameEmail support@inversenergy.com with the project name.
The maximum number of projectsYour plan’s monthly project limit is reached. See Subscription plans.

InverseHub

What you seeWhat to do
New results don’t appear after an uploadRefresh the page, and check the Modeling Phase selected at the top.
A path you need isn’t in the Rating System listEach code lists only its own compliance paths. Check the Energy Code Used. For an IECC project that uses ASHRAE 90.1 instead, choose the 90.1 edition as the code.
“Select a BPF … under Performance Calculations first”Add the performance calculation (+) before the conclusion.
“Enter the required energy credits … first”Add the cost budget calculation (+) with the credits, then the conclusion.
“Select the eGRID subregion under zEPI Calculations first”Add the zEPI calculation (+) with the subregion, then the conclusion.
“Pick the project’s province or territory under General Information”A LEED project in Canada needs its province or territory for its GHG factors. Choose it in eGRID Subregion under General Information, then add the conclusion.
“That code isn’t right, or it has expired” when commentingUse the most recent code email, within 15 minutes, or select Send a New Code. After five wrong tries, send a new code.
“Too many codes were sent to this email”Five codes an hour can go to one email. Wait an hour, or use your invitation’s link.
“Only the client and the people the modeler invited can comment”The modeler limited comments to the client and the project team. Use the email your invitation came to, or ask the modeler to invite you.
View only on a report, or “Only the client can comment”Only the project’s client can comment on this report. You can still read it and download the PDF.
“InverseHub has no tables for this code and climate zone yet” in Fill BaselineFill those Baseline rows yourself. See What gets filled.
Values like “x.xx EER” after Fill BaselineThey’re placeholders. Replace them with your project’s values.
A red note that the code doesn’t allow the methodYou picked a calculation method the code doesn’t use. The result is for reference only. Pick the code’s method in the calculation dialog.
Monthly Project Limit ReachedWait for next month’s reset, or upgrade your plan. See Subscription plans.

Still stuck? Email support@inversenergy.com with the project name, the phase and a screenshot of the message.
