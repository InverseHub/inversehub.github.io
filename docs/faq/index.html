What are the necessary setups for reading EnergyPlus outputs?

SimReader reads the LEED Summary, Building Energy Performance and Tariff Report tables in eplustbl.html. If they’re missing, add the output tables to your IDF file and run the simulation again. The objects to copy are in EnergyPlus and OpenStudio.

Which simulation programs work with InverseHub?

eQUEST (DOE-2) and EnergyPlus, including the programs that run EnergyPlus, such as OpenStudio and DesignBuilder. See Prepare your model output.

Where can I locate the energy model results?

eQUEST writes .SIM files next to the project’s .pd2 and .inp files. EnergyPlus writes eplustbl.html in the run’s output folder. See Where to find the report files.

Why doesn’t SimReader list my project?

SimReader lists only pinned projects. Pin the project in InverseHub, then select Refresh next to Project Name in SimReader.

Can I average several baseline runs?

Yes. Add all the baseline files (for example the four orientations) to Baseline(s), and SimReader averages them. The first file supplies the utility rates and unmet load hours.

Why can’t I choose the Performance Rating Method for an IECC project?

Each energy code lists only its own compliance paths, and the IECC’s is Total Building Performance. If your project uses the ASHRAE 90.1 alternative the IECC allows, choose that 90.1 edition as the Energy Code Used.

Can I change the baseline values after Fill Baseline?

Yes. Fill Baseline only writes text into the Baseline column. Edit any row afterwards, and replace placeholders such as “x.xx EER” with your project’s values.

Do reviewers need an InverseHub account?

No. Anyone with the link can view the report and comment on it after confirming their email with a code. People you invite comment straight from the invitation email. Only clients who follow all their projects need an account.

How do I bring back a phase I removed?

Add it again with Add a Phase, or upload it again from SimReader. Its earlier results come back.

What are SimReader default units?

kWh for electricity, therm for natural gas, gallons for fuel oil, MBtu for district energy and kBtu for the other fuels. The full table is in SimReader units.

What happens if I don’t renew my subscription?

You keep all your projects and can still open, edit and share them. Your account moves to the free Starter plan, which allows 3 new projects a month. See Account and subscription.
