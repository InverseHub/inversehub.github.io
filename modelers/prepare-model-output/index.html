Prepare your model output

SimReader reads the reports your simulation already writes. Check these settings before you run the final simulations, so the upload works the first time.

On this page
  • For every model
  • eQUEST (DOE-2)
  • EnergyPlus and OpenStudio
    • Output tables SimReader needs
    • Example utility rates
  • DesignBuilder
  • Where to find the report files
  • Units SimReader uses

For every model

  • Include utility rates. InverseHub compares the designs by energy cost, and SimReader takes the rates from the reports. A model without rates can’t be read.
  • Use the same rate names in the baseline and proposed models. After reading, SimReader warns you when the rate names differ for a meter, because the two designs would then be priced differently.
  • Keep unmet load hours low. SimReader shows them for both designs and marks a total over 300 hours in red.

eQUEST (DOE-2)

SimReader reads the ES-D (energy cost summary) and PS-F (energy end-use summary) reports of the .SIM file. eQUEST writes both by default once the model has utility rates.

The ES-D report prints only the first 4 characters of each meter name. Keep meter names to 4 characters (for example EM1, EM1A, FM1), or make sure the first 4 characters differ. SimReader shows a Meter name warning when two meters in one file share their first 4 characters.

EnergyPlus and OpenStudio

SimReader reads three groups of tables in eplustbl.html (or eplustbl.htm): LEED Summary, Building Energy Performance and Tariff Report.

If SimReader says Report tables missing, add the objects below to your IDF file and run the simulation again.

Example utility rates

Your model needs utility rates for SimReader to read it. If it has none yet, these two flat rates (electricity and natural gas) are an example to adapt. Use your project’s actual tariffs for compliance work.

  ,                                       ! Season Schedule Name
  ,                                       ! Month Schedule Name
  ,                                       ! Demand Window Length

DesignBuilder

DesignBuilder runs EnergyPlus, so the EnergyPlus tables above apply. To get the report file, open Simulation > Summary and select Export in the Help panel.

Where to find the report files

SoftwareFileWhere
eQUEST.SIM (one per run)The folder of the .pd2 and .inp files, usually Documents\eQUEST 3-65 Projects\{project}
EnergyPluseplustbl.htmlThe folder of the .idf file, or the output folder you chose for the run
OpenStudioeplustbl.html or eplustbl.htm{folder of the .osm}\{model name}\reports\ or \run\
DesignBuildereplustbl.htmExported from Simulation > Summary (see above)

Units SimReader uses

SimReader converts every report to the same units, whatever the report uses (joules, GJ, MMBtu and so on). See SimReader units.
