Read and upload results with SimReader

SimReader reads your baseline and proposed reports, shows the results for you to check, then uploads them to a phase of your InverseHub project.

On this page
  • The Project page
    • Which files go where
  • The Results page
  • Upload to InverseHub
  • Save your SimReader project
  • After the upload: split an end use

The Project page

  1. Project Name: your pinned InverseHub projects. Select Refresh to reload the list after you pin a project.
  2. Modeling Phase and Client Name: filled in from InverseHub. Reload from InverseHub fetches them again. If you change the client here, the upload changes it for every phase of the project.
  3. Analysis Type: must match the project (Standard Baseline, Custom Baseline or Parametric Analysis).
  4. Files: drag .SIM, .htm or .html files onto the tiles, or select a tile to browse.

Which files go where

Analysis typeLeft tileRight tile
Standard or Custom BaselineBaseline(s): one or more baseline runs. Several runs (such as the four orientations) are averaged.Proposed: one file. If you add several, they’re averaged too.
Parametric AnalysisBase Design: one file.ECM(s): one file per measure, numbered in list order. Leave it empty to report the base design alone.

The order matters. The first file in each list supplies the utility rates, the DOE-2 or EnergyPlus version and the unmet load hours. Use the up and down arrows, or drag a file within its list, to reorder. Remove takes the selected files off the list.

Select Next: Results when the files are in place.

The Results page

SimReader reads the files as you arrive, and again whenever the file list changes. Reload reads them again, for example after you rerun a simulation. ‹ Edit files goes back to the Project page.

Check each section before uploading:

  • Utility Rates: the rate of each meter in each design. Untick Include? to leave a meter out. If the baseline and proposed rate names differ, SimReader warns you after reading.
  • On-Site Renewable Energy Production and Exceptional Calculation: select + Add to enter them. They’re subtracted from the proposed design. The annual energy cost is calculated from the energy and the proposed design’s rate until you type your own.
  • Energy Summary by End Use: energy, demand and savings by end use. Tick Process for end uses that are process loads.
  • Total Energy Performance and Simulation Information: totals, process load share and unmet load hours. A total over 300 unmet hours is shown in red.

Upload to InverseHub

  1. Select Upload to InverseHub. You need to be signed in (Settings > Sign in).
  2. If the phase doesn’t exist on InverseHub yet, SimReader asks whether to create it. If it already has results, SimReader asks before replacing them.
  3. Refresh the project page in InverseHub to see the new results.

The upload also fills Simulation Program and Weather File in the project’s Energy Model Information.

Save your SimReader project

Use Save or Save As (Ctrl+S, Ctrl+Shift+S) to keep the file lists, the entries you added and the results in a .ine file. Open (Ctrl+O) brings them back later.

After the upload: split an end use

Simulation programs have a fixed set of end uses. To report part of one separately, for example the parking garage fans inside miscellaneous equipment:

  1. In InverseHub, on Energy Summary by End Use, select Split an end use (+).
  2. Choose the end use to split, tick Process load if the new end use is one, and enter its consumption and demand.
  3. Select the new end use’s name later to edit or delete it.

Splitting isn’t available for Parametric Analysis projects.
